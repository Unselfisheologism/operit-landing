Twent automates anything on Android — UI automation, shell commands,
workflows, triggers, and subagent delegation.

## Methods

 **UI Automation** — control any app by tapping/swiping

 **Shell** — run Linux commands and scripts

 **Intents** — launch apps, send broadcasts

 **Workflows** — multi-step automations with triggers

## Triggers

 **Manual** — start on demand

 **Scheduled** — run at specific times

 **Event-Based** — react to system or app events

## Subagents

The AI agent can delegate tasks to subagents for parallel or specialized work, while keeping you in control.
