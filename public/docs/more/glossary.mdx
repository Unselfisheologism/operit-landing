The Twent docs use some technical words. Here's what each one means — the same terms are clickable wherever they appear in these docs.

| Term | What it means |
| --- | --- |
| [APK](https://en.wikipedia.org/wiki/Apk) | The installation file for Android apps — like an installer on a PC. |
| [Sideloading](https://en.wikipedia.org/wiki/Sideloading) | Installing an app from outside the official Play Store. |
| [Play Protect](https://support.google.com/googleplay/answer/2812853) | Google's app scanner. It sometimes warns about apps that aren't from the Play Store, even safe ones. |
| [Permission](https://support.google.com/android/answer/9431959) | A capability you grant an app — camera, storage, seeing your screen, etc. |
| [API](https://en.wikipedia.org/wiki/API) | "Application Programming Interface" — a way for two programs to talk to each other. |
| [API key](https://en.wikipedia.org/wiki/API_key) | A secret password-like string that identifies you to an online service. Twent uses one to talk to your AI provider. |
| [AI model / LLM](https://en.wikipedia.org/wiki/Large_language_model) | The "brain" that powers AI chat — e.g. GPT, Claude, or open models like Llama. |
| [Provider](https://en.wikipedia.org/wiki/List_of_chatbots#Large_language_models) | A company that serves AI models through its API (e.g. Nous Research, NVIDIA). |
| [Open-weights model](https://huggingface.co/models) | An AI model anyone can download and run themselves. |
| BYOK | "Bring Your Own Key" — the app is free; you supply your own provider API key. |
| [Ubuntu / Linux terminal](https://en.wikipedia.org/wiki/Ubuntu) | A text interface to a full Linux operating system — here, running inside Twent on your phone. |
| [MCP](https://modelcontextprotocol.io/docs/getting-started/intro) | Model Context Protocol — an open standard for giving AI agents extra tools (search, GitHub, databases…). |
| [MCP server](https://modelcontextprotocol.io/docs/learn/architecture) | One tool package speaking MCP. Can be hosted online or run locally on your phone. |
| STDIO | An MCP server that runs as a local program on your device rather than on the internet. |
| streamable-http | An MCP server hosted on the internet that Twent talks to over the network. |
| [Skill](https://agentskills.io) | A ready-made instruction pack that teaches the agent how to do a specific job well. |
| [CLI](https://en.wikipedia.org/wiki/Command-line_interface) | Command-Line Interface — a program you drive by typing commands instead of tapping buttons. |
| Agent CLI | An AI agent (like Claude Code) that runs as a CLI program in a terminal. |
