Full Ubuntu 24 environment on your phone — apt, Python, Node.js, vim,
Git, everything.

Both you and the AI agent can use the built-in terminal. You can also run agent CLIs such as Claude Code or Codex inside the terminal.

## Shell Tools


| Tool | Description |
| --- | --- |
| terminal | Execute commands (supports background, PTY) |

## Package Management

```
`apt update
apt install python3-pip
pip install requests
npm install -g typescript`
```

## Permission Levels


| Level | Access |
| --- | --- |
| Standard | Android shell |
| ADB | pm, am, dumpsys |
| Root | Full su access |
| Shizuku | Elevated without root |
