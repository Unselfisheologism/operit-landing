[MCP](https://modelcontextprotocol.io/docs/getting-started/intro) (Model Context Protocol) is an open standard for plugging extra tools into an AI agent. An [MCP server](https://modelcontextprotocol.io/docs/learn/architecture) can do anything from web search to GitHub management, and Twent speaks it natively.

## Server types Twent accepts

Twent works with two kinds of MCP servers:

- **streamable-http** — servers hosted somewhere on the internet; Twent talks to them over the network
- **STDIO** — servers that run as a small program right on your phone (inside the built-in terminal)

## Authentication: the three flavors

**1. Browser-based login** — some servers let you sign in through a browser flow, like a normal "Log in with…" button. [GitHub's MCP server](https://github.com/github/github-mcp-server), for example.

**2. Auth token** — others need you to paste a credential ([an API key or access token](https://en.wikipedia.org/wiki/API_key)) into that server's configuration. The Apify server works this way.

**3. No authentication** — some remotely-hosted servers need nothing at all, like `https://mcp.deepwiki.com/mcp`. And some run **entirely locally** on your phone, like the built-in **ddg-search** server.

## Discovering servers

You don't have to hunt for configs yourself:

- Browse and search **publicly-published MCP servers** from sources like [GitHub](https://github.com/topic/model-context-protocol) and [mcpservers.org](https://mcpservers.org) — right inside the MCP section of Twent
- Your Twent agent can also **install and run MCP servers on demand**, if it thinks one would help with the task at hand

## Managing servers

- Everything you've installed appears in the **"My Servers"** section of the MCP tab
- Servers can be enabled and disabled from the same tab

:::tip[Start here]
The built-in **ddg-search** server gives your agent web search. Start it once your [terminal setup](/features/terminal) has finished — see [Start Using Twent](/getting-started/start-using-twent).
:::
