Skills are ready-made instruction packs that teach your agent how to do specific jobs well — writing styles, workflows, tool recipes. Find them under **Plugins → Skills tab**.

## Browsing and installing

Browse through and search the skill catalog right inside the Skills tab. Once installed, your Twent agent can call those skills whenever they're useful.

## Tagging a skill with "/"

Want the agent to use a particular skill? Type `/` at the start of your prompt followed by the skill's name, and Twent will make the agent refer to exactly that skill.

Example: typing `/copywriting Write a launch tweet` points the agent straight at the copywriting skill.

## My section

Everything you've installed appears in the **"My"** section of the Skills tab.

:::note
Your Twent agent can also install and use skills **on demand** — when it thinks a skill would help with what you asked.
:::
