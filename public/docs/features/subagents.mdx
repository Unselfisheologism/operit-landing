The Twent agent can delegate **subagents** — helper agents that carry out the specific tasks the main agent assigns them. This lets bigger jobs get split into pieces and done while the main agent stays focused on coordinating.

## Where to see them

Bots and subagents can both be viewed from the **"Bots & Tasks"** page, which gives you a bird's-eye view of everything through a calendar-like UI.
