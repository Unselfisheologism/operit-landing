Twent has two chat modes:

- **AI Chat page** — the dedicated chat screen inside the app
- **Overlay AI Agent** — activated through **home/power-button-long-press**

Use the AI Chat page for longer conversations. Use the overlay AI Agent when you need help while using another app.
