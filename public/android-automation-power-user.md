# Android Automation for Power Users — Twent

Twent is the Android automation app for power users who want desktop-class control on their phone. UI automation, Tasker plugin, floating overlay, MCP tools, and 1000+ app integrations.

## Automation primitives
- tap, swipe, scroll, type, screenshot, get_text, press_key, open_app.
- Visual workflow builder with triggers, conditions, loops, actions.
- Scheduled workflows and event-based triggers.

## Twent vs Anything LLM
Anything LLM is the best open-source RAG system for desktops. Twent is the Android-native equivalent with terminal, device automation, and MCP plugins.

## Twent vs Manus
Manus is a browser-based autonomous agent. Twent is the Android-native agent with local terminal, local models, and deep system integration.

## Twent vs OpenClaw
OpenClaw is an open-source desktop AI assistant. Twent is the Android-native implementation with terminal and device automation.
