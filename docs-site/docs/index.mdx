Twent runs on **Android 8.0+** and gives you a real AI assistant that can see your screen, control any app, run shell commands, browse the web, manage files, and connect to external tools — all from a floating bubble or the main chat interface. The agent can also install MCP servers and skills for itself, delegate to subagents, and ask you for clarification before hard decisions.

## Why Twent exists

Most AI assistants live in a chat bubble and can't touch your device. Twent is different — it runs **on your phone** with full access to the OS, giving AI real agency: reading your screen, tapping buttons, running commands, and managing files.

## What Twent can do

<Accordion>
  <AccordionItem title="Be your agentic assistant">
    Twent's AI agent connects to MCP servers and installs skills for itself. It can automate tasks with a manual, scheduled, or event-based trigger, and it can delegate work to subagents — you stay in control while the agent and its subagents do the work.
  </AccordionItem>
  <AccordionItem title="Automate any Android app">
    The AI can see your screen via Accessibility service, tap buttons, fill forms, swipe, scroll, and type — automating any app without API access or special integrations. It can also explain what is on your screen.
  </AccordionItem>
  <AccordionItem title="Run a full Linux environment">
    Built-in Ubuntu 24.04 terminal — no root required. Install packages with apt, run Python scripts, use Git, SSH to servers, and build software. Both you and the AI agent can use the terminal, and you can run agent CLIs like Claude Code or Codex inside it.
  </AccordionItem>
  <AccordionItem title="Manage files and code">
    Read, write, search, and edit files on your device. Built-in filesystem and Git UIs let you browse folders and control repositories visually. Compress, decompress, and transfer files.
  </AccordionItem>
  <AccordionItem title="Browse the web">
    Fetch web pages as markdown, search with DuckDuckGo/Bing/Scholar, download files, and use a built-in browser with JavaScript execution.
  </AccordionItem>
  <AccordionItem title="Process media">
    Full FFmpeg engine, camera integration, OCR, image analysis, speech-to-text, and text-to-speech — all built in.
  </AccordionItem>
  <AccordionItem title="Run local AI on-device">
    Use local models directly on your phone — Twent supports GGUF/MNN/llama.cpp/local providers, so you can run AI offline without relying on cloud providers.
  </AccordionItem>
  <AccordionItem title="Ask before acting">
    If the agent has a doubt, it can pause and ask for your input before making a hard decision.
  </AccordionItem>
</Accordion>

## Quick start

<Steps>
  <Step title="Download Twent">
    Get the latest APK from [twent.xyz](https://twent.xyz). The APK is ~80MB and includes everything you need.
  </Step>
  <Step title="Install and grant permissions">
    Open the APK, enable "Install from unknown sources" if prompted, then grant the requested permissions. Storage and Network are required; Accessibility enables UI automation.
  </Step>
  <Step title="Configure your AI provider">
    Go to Settings → Model & Parameters Configuration. Add your API key (OpenAI, Claude, Gemini, OpenRouter, or many more). Twent is completely free — you only pay your chosen model provider.
  </Step>
  <Step title="Start chatting">
    Tap the floating bubble or open the chat screen. Ask Twent to do anything — run commands, automate apps, browse the web, manage files, or install new skills and MCP servers for itself.
  </Step>
</Steps>
