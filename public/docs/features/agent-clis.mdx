An [Agent CLI](https://en.wikipedia.org/wiki/Command-line_interface) is an AI agent that runs as a program in a terminal instead of in a chat app — tools like Claude Code or Codex that read, write, and run code for you.

The **Agent CLIs** page of Twent lets you browse all the supported agent CLIs and install them with one tap into the built-in [Ubuntu](https://en.wikipedia.org/wiki/Ubuntu) terminal:

- claude-code
- codex
- hermes-agent
- amp-code
- pi-agent
- kilocode
- …and many more (aider, opencode, gemini-cli, qwen-code, goose, cline, and others)

:::tip
Make sure your [Terminal setup](/features/terminal) has completed first.
:::
