# Enterprise AI Agent for Android — Twent

Twent is the enterprise-ready Android AI agent with BYOK encryption, zero telemetry mode, local GGUF models, and MCP tools. Deploy across teams without sending sensitive data to the cloud.

## Enterprise controls
- Local AI inference with encrypted API key storage.
- MCP server support for internal tools and databases.
- Ubuntu terminal for admin scripts and audits.
- Skills and workflows for repeatable operations.

## Twent vs Microsoft Copilot
Copilot is best for Microsoft 365 creativity. Twent is best for Android device control, terminal workflows, and internal tool integrations.
