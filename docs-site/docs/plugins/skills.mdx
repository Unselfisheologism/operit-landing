SKILL.MDs are markdown-based skill files that teach the AI Agent specific behaviors, workflows, and tool usage.

## How Skills Work

 When you or the agent installs a SKILL.MD, Twent loads its instructions and tools automatically when the skill is relevant.

## Managing Skills

 Open the app → `Plugins` page → `Skills`

 Install, update, or remove skills from there.
