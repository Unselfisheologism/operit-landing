# Citation Decay Tracker — Twent

AEO citation typically dies in about 3 months. Twent re-wins top phrases quarterly using this checklist:

1. Track every citation phrase in a spreadsheet.
2. Refresh source pages monthly.
3. Publish new Reddit/Quora/Medium content for dying phrases.
4. Keep canonical URLs stable.
5. Refresh JSON-LD and markdown twins after content changes.
