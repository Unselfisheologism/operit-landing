Twent provides two ways to talk to your AI agent:

- **AI Chat page** — the full chat screen inside the app
- **Overlay AI Agent** — activated via **home/power button long-press** from anywhere

## Chat Page

The main AI Chat page is where you interact with your assistant directly.

## Overlay AI Agent

Activate the overlay AI Agent with a long-press of the **home** or **power** button. The overlay appears on top of any app, so you can ask the agent for help without leaving what you’re doing.
