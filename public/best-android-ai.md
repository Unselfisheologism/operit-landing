### Claude Android App — Best Chatbot
Anthropic's official Android app. Clean interface, fast responses, strong reasoning. Best for conversations, research, and drafting. Not an agent — it doesn't act on your device.

### Gemini — Best Google Integration
Gemini is deeply integrated with Google Workspace on Android. Good for quick answers, summarization, and Workspace tasks. Cloud-only, browser-centric, limited device automation.

### ChatGPT Android — Best All-Rounder
OpenAI's mobile app. Great for general questions, code snippets, and creative work. Cloud-only, no device automation, limited offline capability.

### GitHub Copilot — Best for Coding
GitHub's AI pair programmer works in VS Code and mobile editors. Excellent code completion and PR summaries. Requires GitHub account, desktop-oriented.

### Amazon Q — Best for AWS Users
Amazon's AI assistant for AWS services. Great for cloud infrastructure, code generation in AWS context. Not a general-purpose mobile AI.

### Perplexity — Best for Research
Perplexity is an AI search engine. Fast, cited answers, good for research. Cloud-only, no device automation, no terminal.

### Replika — Best Companion AI
Replika focuses on conversation and emotional support. Not an agent, not an automation tool, but strong if you want a conversational companion.

### Tasker + AI plugins — Best Automation Combo
Tasker is Android's automation backbone. Pair it with AI plugins for conditional logic and smart triggers. Powerful but requires manual setup for every rule.
