Twent can generate AI media assets — [images](https://en.wikipedia.org/wiki/Text-to-image_model), videos, audio, music, and [3D models](https://en.wikipedia.org/wiki/3D_modeling) — by driving the AI tools **you already use**.

## Set up your generators

There is a **"Media Generators"** section in the Settings page of the Twent app. There you select the apps or websites you use to generate AI media — and more than one can be selected, per category (image, video, audio, music, 3D).

## How it works

When you ask Twent to create a media asset, the agent delegates an [overlay subagent](/features/subagents) that opens your chosen generator — website or installed app — and drives it with UI automation to produce the asset. The first generator in your preference order is the default; if you name one explicitly ("use kling"), Twent uses that instead.

The finished asset stays in the generator tool itself, so you download it from there.

:::note
If a category has no generators configured, the agent will ask you to set one up in **Settings → Media Generators** first.
:::
