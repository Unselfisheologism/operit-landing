Access the AI Agent as a Dynamic Island notch-style overlay from anywhere.

## Activation

 **Home button long-press**

 **Power button long-press**

## Behavior

 The overlay appears as a notch-style bubble on top of the current app.

 You can ask the agent questions, request screen explanations, or start automations without switching apps.
