Model Context Protocol — a standard for giving AI access to external
 tools. You or the AI agent can install MCP servers and skills that expand the agent's capabilities.

## Installing

 Browse `Plugins → MCP → Shop Icon`

 Or add manually via JSON config

 The AI agent can also install MCP servers and skills for itself when needed.
## Popular Servers


| Server | What it does |
| --- | --- |
| Filesystem | Extended file operations |
| Git | Repository management |
| SQLite | Query databases |
| Brave Search | Web search |
| Puppeteer | Browser automation |
