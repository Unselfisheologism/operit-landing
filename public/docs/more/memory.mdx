Persistent knowledge storage that survives across conversations. The AI remembers your preferences, past discussions, and important information — and its memory grows over time. You can view and edit everything in the **AI's Memory** page (Settings → Memory).

## Memory Types

- **User Preferences** — communication style, apps, contacts
- **Conversation Summaries** — key decisions and action items (written automatically after each conversation)
- **Knowledge Base** — notes, reference material, research

## Agent Memory Tools

| Tool | Description |
| --- | --- |
| tw_recall | Search memories by keyword |
| tw_remember | Save a new memory (with category, importance, tags) |
| tw_forget | Delete a memory |
| tw_learn_user / tw_forget_user | Manage the learned user profile |

All memories are stored **locally** on your device. Nothing leaves your device except API calls.
