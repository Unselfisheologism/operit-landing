# Privacy-First AI on Android — Twent

Twent is the privacy-first Android AI assistant. Local GGUF models run fully offline. API keys are encrypted on-device. Zero telemetry, zero tracking, zero data collection.

## Privacy model
- BYOK: your keys never leave your device.
- Local models: Llama, Qwen, Mistral via MNN/GGUF.
- Optional cloud: connect your own API key when you need it.

## Twent vs Replika
Replika is a companion chatbot with cloud models. Twent is a privacy-first agent with local inference, terminal, and automation.

## Twent vs Siri / Bixby
Siri and Bixby are system assistants with limited extensibility. Twent is an open agent platform with MCP, skills, workflows, and full Android access.

## Install
Download Twent from the Play Store or twent.xyz. No account required.
