## 1 · Search and research the web

Through the built-in **ddg-search** [MCP server](https://modelcontextprotocol.io/docs/getting-started/intro), your Twent agent can search the web and research topics on your behalf.

:::note
Start the ddg-search server first if it isn't running — see the [Start Using Twent](/getting-started/start-using-twent) page.
:::

## 2 · Persistent memory

Twent has its own memory. It remembers things across chat sessions, and its memory grows over time the more you use it.

You stay in control — view, edit, or clear everything the AI remembers in the **"AI's Memory"** page in the app.
