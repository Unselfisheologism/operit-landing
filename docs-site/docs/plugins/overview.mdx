Plugins are how Twent extends the AI Agent's capabilities.

The app's **Plugins** page currently supports two plugin types:

- **MCP servers** — external tool providers the agent can use
- **SKILL.MDs** — markdown skill files that teach the agent specific behaviors

You or the AI agent can install and manage these from the app.

## Installing

 Open the app → `Plugins` page

 Browse available MCP servers and skills, or add them manually

 The AI agent can also install plugins for itself when needed.
