The **Terminal** page is where an entire [Ubuntu Linux](https://en.wikipedia.org/wiki/Ubuntu) environment lives, right inside the Twent app. Both you and your agent can use it to install software, run scripts, manage files, and more.

## First-time setup

The moment you open the Terminal page for the very first time after installing Twent, setup starts **automatically**. It takes about **8–10 minutes**, so leave the app open and let it finish.

:::note[What gets installed?]
Once setup is complete, tap the **"Environment Setup"** button in the bottom-right corner of the Terminal page to see exactly what was installed during those 8–10 minutes.
:::

Many other features depend on this setup being done — including starting MCP servers ([Plugins → MCP](/plugins/mcp)) and installing [Agent CLIs](/features/agent-clis).
