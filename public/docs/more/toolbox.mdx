Built-in utility screens for debugging, development, and system management.

## Development Tools

- **Shell Executor** — run commands directly
- **Terminal** — full terminal emulator (see [Terminal](/features/terminal))
- **File Manager** — browse device files

## System Tools

- **Agent Commands** — run non-chat agent commands like `doctor`, `setup`, and `mcp`
- **Setup Wizards** — guided setup for the terminal environment and accessibility service
- **UI Debugger** — inspect UI hierarchy for automation

Access these from **Settings → Advanced**, alongside Memory, Plugins, Agent CLIs, and Token Config.
