Twent docs are optimized so AI assistants, coding agents, and crawlers can discover, cite, and act on them. This page explains what is enabled and why.

## What this page covers

- `/llms.txt` and `/llms-full.txt`
- page-level Markdown mirrors
- Open in chat and Copy as Markdown
- agent readability manifest
- MCP server
- Ask AI assistant

## llms.txt

Blume emits machine-readable docs so chat assistants and agents can read Twent docs directly.

- `/llms.txt` is a compact index of pages grouped by docs section.
- `/llms-full.txt` contains every page's full Markdown body.

These files update on every docs build.

## Raw Markdown mirrors

Every page exposes agent-readable Markdown:

- `/tools/overview.md` plain Markdown version
- `/tools/overview.mdx` raw MDX source

This makes it easy for LLMs to ingest exact page content.

## Open in chat

Use **Open in chat** to send a page to an AI assistant pre-filled with a prompt that points at the page's Markdown source. It works with ChatGPT, Claude, Cursor, and others.

## Ask AI

Twent docs can host an in-page assistant grounded in Twent content. It answers from the docs index and cites pages. It is currently opt-in at the site level.

## MCP server

A hosted MCP endpoint lets agents search and read Twent docs without scraping. It exposes read-only tools for docs search, page fetching, and navigation.

## Agent readability

`/agent-readability.json` indexes the agent-facing surface so tools can discover Twent docs in one request.

## Keep content citation-ready

- Use comparison phrasing when it fits: `ChatGPT vs Twent`, `Claude on Android`, `Copilot Android`
- Add concrete sections such as installation, setup, permissions, tools, and troubleshooting
- Keep pages short, scannable, and factual
