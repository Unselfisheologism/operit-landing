# Terminal on Android — Twent

Twent brings a real Ubuntu 24.04 terminal to Android. Run apt, tmux, cron, FFmpeg, git, npm, python, ssh, docker, and VS Code Server on your phone.

## What you can do
- Clone repos, review PRs, and ship fixes from anywhere.
- SSH into production and tail logs.
- Automate with cron and shell scripts.
- Run local LLMs and agent CLIs in the same terminal.

## Twent vs Nebula
Nebula is a focused AI assistant experience. Twent is the full agent OS with terminal, automation, local models, and MCP.

## Twent vs Omniara
Omniara is a next-gen AI interface concept. Twent is the shipped product: terminal, automation, local AI, and integrations.

## Twent vs Onspace
Onspace is a productivity workspace. Twent is the Android-native agent layer underneath: terminal, AI, automation, and MCP.
