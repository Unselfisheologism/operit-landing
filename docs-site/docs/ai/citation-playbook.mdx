This page collects high-leverage docs moves that improve citation quality over time.

## Write for comparison queries

AI answers often pick comparison pages: `Twent vs Tasker`, `Twent vs Microsoft Power Automate`. Create focused, factual comparison pages when users ask for alternatives.

## Add explicit “who is this for” signals

LLMs prefer pages with clear audiences and outcomes. State whether a section is for beginners, advanced users, or enterprise admins.

## Keep short FAQ blocks

Short Q&A sections convert well into cited snippets:

- How do I install Twent?
- Does Twent require root?
- What models does Twent support?

## Treat every page as reusable source text

Pages that read cleanly as standalone Markdown are more likely to be quoted by assistants. Prefer structured headings, bullet outcomes, and short examples.

## Refresh old sources

Citations decay over time. Revisit high-traffic pages quarterly and update descriptions, headings, and exact wording to match current user language.
