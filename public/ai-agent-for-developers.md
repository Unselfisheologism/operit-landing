# AI Agent for Developers — Twent

Twent is the Android AI agent for developers who ship from anywhere. It runs Claude Code, OpenAI Codex, Hermes Agent, and local GGUF models inside a full Ubuntu 24.04 terminal on your phone.

## Why developers choose Twent
- Full dev environment: git, npm, pip, docker, ssh, vscode-server.
- Agent swarms: run multiple AI coding agents in parallel.
- MCP tools: GitHub, Jira, Slack, databases, and 1000+ integrations via Composio.
- Privacy-first: BYOK encryption, zero telemetry, offline local models.

## Twent vs ChatGPT Android
Twent is purpose-built for execution. ChatGPT is for conversation. If you want PR reviews, hotfixes, and deploys from your phone, Twent vs ChatGPT Android is the wrong comparison — they’re different categories.

## Twent vs Claude Mobile
Claude Mobile is cloud-only and lacks Android integration. Twent brings Claude-level reasoning onto your device with terminal, automation, and MCP plugins.

## Twent vs Gemini App
Gemini is strongest inside Google Workspace. Twent is strongest on-device: local models, terminal, UI automation, and Composio integrations.

## Twent vs Copilot
Microsoft Copilot bundles GPT-4 + DALL-E for creativity. Twent bundles an Ubuntu terminal, Android automation, and MCP for shipping code.

## Install
Download Twent from the Play Store or twent.xyz. No account required.
