An [API key](https://en.wikipedia.org/wiki/API_key) ("token") is what connects Twent to an [AI model](https://en.wikipedia.org/wiki/Large_language_model) provider.

The **Token Config** page lets you get the key for any provider of your choice **from that provider's own website, right inside the Twent app** — no juggling between your phone browser, email, and the app. Sign up or log in on the provider's page, generate the key, and Twent picks it up.

Prefer to configure manually? You can always paste keys yourself under **Settings → Model Settings** (see [Start Using Twent](/getting-started/start-using-twent)).
